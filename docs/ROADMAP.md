> 본 문서는 [docs/PRD.md](./PRD.md)를 기반으로 작성된 개발 로드맵입니다.

| --- | --- | --- |

## Phase 1: 프로젝트 초기 설정

**예상 소요 시간**: 1-2일

**이유**: 견고한 기반 없이는 기능 개발이 어려움

### 작업 항목
- Next.js 프로젝트 구조 설정 (TypeScript, Tailwind CSS, shadcn/ui 초기 설정 포함)
- Notion API 연동 환경 구축 (`@notionhq/client` 설치, `NOTION_API_KEY`/`NOTION_DATABASE_ID` 환경 변수 설정)
- Notion 데이터베이스 생성 및 Integration 연결 (PRD 4번 구조 기준)
- 기본 레이아웃 구조 생성 (폴더 구조, 라우팅 뼈대)

### 완료 기준
- [ ] `npm run dev`로 로컬 서버가 정상 구동됨
- [ ] Notion API 키로 데이터베이스 조회가 성공적으로 이루어짐 (테스트 스크립트 또는 API 라우트 기준)
- [ ] Tailwind CSS 및 shadcn/ui가 정상 적용됨을 확인
- [ ] 기본 폴더 구조(`app/`, `components/`, `lib/` 등)가 정의됨

---

## Phase 2: 공통 모듈 개발

**예상 소요 시간**: 2-3일

**이유**: 모든 기능에서 재사용되는 코드를 먼저 만들어야 중복 방지

### 작업 항목
- Notion API 공통 함수 구현 (`fetchPages`, `fetchPageContent`)
- 공통 컴포넌트 구현 (`Header`, `Footer`, `Card`)
- 공통 타입 정의 (`Post`, `Category`)

### 완료 기준
- [ ] `fetchPages`로 발행된(Status: 발행됨) 글 목록을 정상적으로 가져옴
- [ ] `fetchPageContent`로 특정 페이지의 본문 블록을 정상적으로 가져옴
- [ ] `Post`, `Category` 타입이 Notion 데이터베이스 속성과 일치함
- [ ] `Header`, `Footer`, `Card` 컴포넌트가 스토리 수준에서 독립적으로 렌더링 가능함
- [ ] 공통 함수/컴포넌트에 대한 타입 에러 없이 빌드 성공

---

## Phase 3: 핵심 기능 개발

**예상 소요 시간**: 3-4일

**이유**: 블로그의 가장 기본이 되는 기능

### 작업 항목
- 블로그 글 목록 페이지 (`/`) 구현
- 블로그 글 상세 페이지 (`/posts/[slug]`) 구현
- Notion 컨텐츠(블록) 렌더링 구현 (텍스트, 이미지, 코드 블록 등 주요 타입 우선)

### 완료 기준
- [ ] 홈 화면에서 발행된 글 목록이 최신순으로 표시됨
- [ ] 글 목록의 각 항목 클릭 시 해당 글 상세 페이지로 정상 이동함
- [ ] 상세 페이지에서 Notion 본문(텍스트/이미지/코드 블록 등)이 깨지지 않고 렌더링됨
- [ ] 존재하지 않는 slug 접근 시 404 처리됨

---

## Phase 4: 추가 기능 개발

**예상 소요 시간**: 2-3일

**이유**: 핵심 기능이 완성된 후 부가 기능 추가

### 작업 항목
- 카테고리 필터링 (`/category/[category]`) 구현
- 검색 기능 구현 (제목/태그 기준)
- SEO 최적화 (메타 태그, OpenGraph, sitemap 등)

### 완료 기준
- [ ] 카테고리 선택 시 해당 카테고리 글만 필터링되어 표시됨
- [ ] 검색어 입력 시 제목/태그 기준으로 정확히 일치하는 결과가 표시됨
- [ ] 각 페이지에 적절한 `title`, `description`, OpenGraph 메타데이터가 설정됨
- [ ] sitemap.xml / robots.txt가 정상 생성됨

---

## Phase 5: 최적화 및 배포

**예상 소요 시간**: 1-2일

**이유**: 기능이 완성된 후 품질 향상

### 작업 항목
- 성능 최적화 (이미지 최적화, ISR/캐싱 전략 적용 등)
- 반응형 디자인 개선 (모바일/태블릿/데스크톱 대응 점검)
- Vercel 배포 및 환경 변수 설정

### 완료 기준
- [ ] Core Web Vitals 기준 주요 지표(LCP, CLS 등)가 양호한 수준임
- [ ] 모바일/태블릿/데스크톱 각 브레이크포인트에서 레이아웃이 깨지지 않음
- [ ] Vercel에 배포 완료 및 프로덕션 URL에서 정상 동작 확인
- [ ] Notion에서 글 작성/수정 후 재검증(revalidate) 주기 내에 블로그에 반영됨

---

## 참고 사항

- 각 Phase의 소요 시간은 1인 개발 기준 예상치이며, 실제 진행 상황에 따라 조정될 수 있습니다.
- Phase 간 의존성이 존재하므로(예: Phase 3은 Phase 2의 공통 모듈에 의존) 순서를 준수하는 것을 권장합니다.
- MVP 범위는 [docs/PRD.md](./PRD.md)의 6번 항목을 따릅니다.
